# Harsh Kumar / harsh5ingh.tech

Personal portfolio built in the existing Next.js 16 App Router project with TypeScript, Tailwind CSS 4, Framer Motion, Lucide React, and next-themes.

## Local development

```sh
npm install
npm run dev
```

Use the Local URL printed by Next.js. An existing development server may already occupy port 3000.

## Public configuration

`src/config/site.ts` is the typed source of public identity, contact details, profile links, canonical URL, and project links. Default contact/profile values come from the supplied resume; the display name is Harsh Kumar. Repository links are source-provided, not a guarantee of public availability.

Identity and profile defaults do not need an environment file. All project destinations are optional environment values. If overriding configuration, copy `.env.example` to `.env.local` and replace `example.com` and the placeholder email before building. Optional blank project live URLs remain hidden; Halo has no default repository or live URL. Leave any project repository variable empty to show an unavailable action.

Every `NEXT_PUBLIC_*` value is public and embedded at build time. Never place API keys, credentials, tokens, or database URLs in those variables. This portfolio has no backend integrations and needs no secrets. Rebuild after changing public environment values.

## Obsidian & Ember design system

Edit the `:root` and `.dark` token blocks in `src/app/globals.css`. Tailwind 4 exposes the same semantic colors through `@theme inline`. Keep large surfaces neutral; use `--accent` for decorative accents and large headings, `--accent-text` for small text, `--accent-action` with `--accent-foreground` for filled controls, and `--accent-hover` for their hover state. Use `--control-border` for necessary control boundaries; `--border` is deliberately quieter and only suitable for decorative separators. Keyboard focus uses `--focus-ring`.

Exact light Ember (`#D45D35`) has 3.47:1 contrast on the page and 3.88:1 on white, so it is unsuitable for normal text or white button labels. The derived light text/action color (`#A33B1C`) resolves this. Dark Ember passes on all theme surfaces. The contrast script checks 78 combinations, including editorial panels and the photographic overlay over a worst-case white image pixel. Base-theme text pairs reach at least 4.75:1 in light and 4.93:1 in dark; control/focus/chart pairs reach at least 3.27:1 and 3.96:1 respectively. These calculations are not a full browser accessibility audit.

After editing tokens, regenerate the social-preview palette and icons, then run the check:

```sh
node scripts/design-system.mjs --write-assets
node scripts/design-system.mjs
```

`src/config/brand-palette.json`, `src/app/icon.svg`, and `src/app/favicon.ico` are generated snapshots because standalone assets cannot inherit page CSS. The social image imports that generated JSON. Do not hand-edit these generated colors. The script also checks for raw colors outside the CSS theme blocks and stale generated assets.

The original color inventory covered the then-current screens and branding assets. Obsolete walkthrough and cinematic selectors were removed during cleanup; shared theme tokens remain for compatibility with the contrast and branding checks. Unreferenced starter SVGs have been removed. Existing next-themes system defaults, persisted preferences, hydration handling, and reduced-motion behavior remain intact. Browser access was disabled during this palette update, so both themes still need a visual pass at mobile and desktop sizes, including keyboard focus and real prototype frames.
